# OpenGL Billiards

C++와 OpenGL로 제작한 3D 당구 시뮬레이션입니다. 큐를 직접 당겨 공을 타격하며,
공과 공·쿠션 사이의 충돌, 충격량, 반발계수와 구름 마찰을 적용했습니다.

## 핵심 기능

- 질량과 반발계수를 고려한 공 충돌 및 쿠션 반사
- 서브 스텝과 반복 충돌 보정을 통한 겹침·터널링 완화
- 실제 마찰력 식을 응용한 시간 기반 감속
- 큐를 당긴 거리와 타격 애니메이션을 연동한 입력 시스템
- 첫 번째 충돌 지점과 반사 방향을 보여주는 점선 궤적 가이드
- 플레이어 카메라, 공 추적 카메라와 탑뷰 미니맵

## 기술 스택

`C++` · `OpenGL` · `GLSL` · `GLEW` · `freeglut` · `GLM`

## 실행 방법

별도의 빌드나 OpenGL 라이브러리 설치 없이 다음 실행 파일을 더블 클릭하면 됩니다.

`Release/컴그최종프로젝트.exe`

`Release` 폴더 안의 셰이더, 모델, 음원 파일은 실행에 필요하므로 실행 파일과 같은 폴더에
유지해야 합니다. Windows의 기본 `OPENGL32.dll`과 OpenGL 3.3 이상을 지원하는 그래픽
드라이버는 필요합니다.

### 소스에서 빌드

`컴그최종프로젝트.sln`을 Visual Studio 2026으로 엽니다.

1. 상단 구성을 `Debug` 또는 `Release`로 선택합니다.
2. 플랫폼을 `x64`로 선택합니다.
3. 솔루션 탐색기에서 `컴그최종프로젝트`를 시작 프로젝트로 설정합니다.
4. `F5`를 누르면 빌드 후 실행됩니다. 디버깅 없이 실행하려면 `Ctrl+F5`를 누릅니다.

솔루션에는 애플리케이션과 `GLEW`, `freeglut` 정적 라이브러리 프로젝트가 들어 있습니다.
GLM은 헤더 전용 라이브러리로 직접 참조됩니다. 세 라이브러리는 모두 `third_party`에 있으므로
인터넷 연결, vcpkg 또는 별도의 라이브러리 설치가 필요하지 않습니다.

Visual Studio 2026의 `v145` 도구 집합을 사용합니다. 다른 컴퓨터에서는 Visual Studio Installer에서
**C++를 사용한 데스크톱 개발**을 설치해야 합니다.

빌드 결과는 다음 경로에 생성됩니다.

- Release: `bin/x64/Release/컴그최종프로젝트.exe`
- Debug: `bin/x64/Debug/컴그최종프로젝트.exe`

셰이더, 모델 및 소리 파일은 빌드할 때 실행 파일 옆으로 자동 복사됩니다.

## 조작

- `←`, `→`: 조준 방향 회전
- `↓` 누르기: 큐를 뒤로 당겨 힘 충전
- `↓` 떼기: 현재 당긴 힘으로 타격
- `1`: 흰 공 / 플레이어 1 시점 선택
- `2`: 주황 공 / 플레이어 2 시점 선택
- `C`: 플레이어 시점 / 기존 공 시점 전환
- `Esc`: 종료
- 창의 닫기 버튼: 종료

## 외부 라이브러리

`third_party`에 포함된 GLEW, freeglut, GLM의 라이선스는 각 라이브러리 폴더에 보존되어 있습니다.
